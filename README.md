# כסף מגיל 16

אתר קורס דיגיטלי בעברית. בלי שרת, בלי בנייה, קבצים רגילים בלבד.

## איך פותחים את זה במחשב (לבדיקה)

האתר בנוי מקבצי JavaScript שנטענים אחד מהשני (`import`). דפדפנים לא מרשים
את זה כשפותחים קובץ ישירות (`file://`), אז צריך שרת מקומי קטן.

1. פותחים טרמינל בתיקייה הזאת:
   ```
   cd <התיקייה של הקורס>
   python3 -m http.server 8913
   ```
2. פותחים בדפדפן: `http://localhost:8913/`
3. לעצירה: `Ctrl+C` בטרמינל.

## עובד גם בלי אינטרנט

אחרי שפותחים את האתר פעם אחת כשיש אינטרנט, הדפדפן שומר עותק שלו
(Service Worker). אחרי זה, כל הקורס עובד גם בלי אינטרנט, חוץ מ:
- צפייה בסרטונים
- שמירת התקדמות בענן (סנכרון בין מכשירים)

## מבנה התוכן, לסוכנים שכותבים שיעורים

- `content/course.js`: רשימת כל 38 השיעורים. כל שיעור הוא `status: 'soon'`
  עד שיש לו קובץ תוכן אמיתי.
- כדי להוסיף שיעור אמיתי: יוצרים `content/lessons/<slug>.js` לפי המבנה
  ב-`SPEC.md` סעיף 4, ואז משנים ב-`content/course.js` את השדה `status` של
  אותו שיעור מ-`'soon'` ל-`'ready'`. זה הכל. אין צורך לגעת בשום קובץ אחר.
- `content/lessons/_fixture.js` הוא שיעור בדיקה בלבד (לא שיעור אמיתי בקורס).
  הוא לא מופיע בשום תפריט. אפשר לראות אותו רק דרך הכתובת
  `#/lesson/_fixture/start`. הוא קיים כדי לבדוק שכל חלקי האתר עובדים.
- `content/sources.js` ו-`content/glossary.js` מכילים כרגע רק ערכי בדיקה
  (`fixture: true`). סוכני תוכן אמורים להוסיף שם ערכים אמיתים ומאומתים.
